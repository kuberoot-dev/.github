# Code of Conduct

The kuberoot project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). We want a place where anyone can take part, ask questions and disagree about ideas, and be treated with respect throughout.

If you experience or witness unacceptable behavior, please contact a maintainer listed in [MAINTAINERS.md](MAINTAINERS.md) privately. Every report is handled in confidence.
