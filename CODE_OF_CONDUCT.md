# Code of Conduct

The kuberoot project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We want the project to be a place where anyone can take part, ask questions, disagree about ideas and be treated with respect while doing it.
