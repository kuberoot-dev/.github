# Security

Please do not report a vulnerability in a public issue. Open the **Security** tab of the affected repository and choose **Report a vulnerability**; the report reaches the maintainers alone. We will acknowledge it, keep you informed while we work on a fix, and credit you when the fix ships, unless you would rather we did not.

The project is experimental: fixes land on `main` and in the latest release of each repository, and older releases are not patched.
