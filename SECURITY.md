# Security

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues.

Report them privately through GitHub: open the **Security** tab of the affected repository and choose **Report a vulnerability**. The report reaches the maintainers only.

We will acknowledge the report, keep you informed while we work on a fix, and credit you when the fix is published, unless you prefer otherwise.

## Supported versions

The project is experimental. Fixes are made on `main` and in the latest release of each repository; older releases are not patched.
